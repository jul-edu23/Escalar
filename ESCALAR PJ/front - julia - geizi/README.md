3.Descrição do Projeto
3.1 Apresentação
O Escalar é um sistema de gestão de plantões para a segurança do Centro de Universitário de Patos de Minas. Utiliza inteligência artificial para automatizar escalas de trabalho, garantindo eficiência, equilíbrio e cumprimento das normas.
 
3.2 Quantidade de Telas (quando aplicável a sistemas/aplicações)
O sistema terá quatro telas: login, calendário, cadastro de colaboradores e avisos
 
3.3 Tecnologias Utilizadas
As tecnologias usadas serão HTML, CSS (Bootstrap) e JavaScript, Python, SQL e IA.
